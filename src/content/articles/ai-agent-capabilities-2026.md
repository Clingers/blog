## 2. 定义与架构

### 2.1 什么是 AI Agent

AI Agent 是**能够自主感知环境、制定计划、使用工具并执行多步任务**的智能系统。与传统的 LLM 对话模式不同，Agent 具备以下核心特征：

- **自主性**：无需人类每步干预，可独立完成复杂任务链
- **工具使用**：调用外部 API、数据库、浏览器、代码执行器等
- **记忆与规划**：维护短期/长期记忆，能分解任务并动态调整计划
- **反馈循环**：从执行结果中学习，修正错误路径


### 2.3 微软工作趋势指数：AI 工作的四种模式

微软研究院将 AI 在工作中的角色归纳为四种模式：

| 模式 | 描述 | 典型场景 |
|:---|:---|:---|
| **委派 (Delegation)** | 将完整任务交给 Agent 自主完成 | 编码、报告生成、数据分析 |
| **协作 (Collaboration)** | 人机协同，Agent 提供建议并迭代 | 文档撰写、代码审查、设计 |
| **询问 (Asking)** | 人类主动提问，Agent 提供事实性回答 | 知识检索、技术支持 |
| **探索 (Exploration)** | Agent 主动发现新信息和模式 | 市场研究、趋势分析 |

### 3.2 详细能力分解

#### 3.2.1 自主任务能力
- **METR 指标**：AI Agent 能持续工作的任务视野（Task Horizon）每 123 天翻倍。按此趋势，2027 年将突破数天级别
- **Claude Opus 4.5/4.6**：SWE-Bench 得分 80.9%，自主工作时长 14.5 小时，可独立完成中等复杂度的软件工程任务

#### 3.2.2 编码与软件开发
- Claude Code 贡献了 GitHub 4% 的提交量
- 编码 Agent 能够：创建项目结构 → 编写代码 → 运行测试 → 调试修复 → 提交 PR 的完整闭环
- 典型场景：代码生成、Bug 修复、代码审查、重构、文档生成

#### 3.2.3 浏览器操作
- 通过 Computer Use 等技术，Agent 可操作任何浏览器界面
- 支持：表单填写、数据抓取、网页交互、多标签管理
- 应用：自动化测试、RPA 替代、信息采集

#### 3.2.4 研究与内容生成
- 深度研究 Agent：从问题定义 → 搜索 → 阅读 → 分析 → 报告生成的完整工作流
- 内容 Agent：文章撰写、社交媒体运营、翻译、SEO 优化
- 学术研究：MIT/Stanford 在生物医学领域验证 Agent 辅助科研决策

#### 3.2.5 多 Agent 协作
- 多 Agent 系统的协作效率比单 Agent 提升 **76%**（通过定向通信优化）
- 典型角色分工：规划 Agent → 执行 Agent → 审查 Agent → 总结 Agent
- 适用于复杂项目管理、大规模代码库重构、分布式研究

> **17,000+ MCP 服务器** 已部署，成为 Agent 工具调用的标准化协议

## 7. 风险与局限

### 7.1 技术风险

| 风险类别 | 具体表现 | 当前缓解措施 |
|:---|:---|:---|
| **幻觉与错误** | Agent 可能生成看似合理但错误的输出 | 验证链、多 Agent 交叉检查 |
| **任务漂移** | 长时间运行中偏离原始目标 | 规划检查点、人类在环确认 |
| **工具调用失败** | 依赖的外部 API 不稳定或变更 | 重试机制、回退策略 |
| **上下文窗口限制** | 长任务中的记忆遗忘 | RAG、层级记忆系统 |

### 7.2 安全与隐私

- **权限失控**：Agent 可能获得超出预期的访问权限 → 最小权限原则 + 审批闸门
- **Prompt 注入**：恶意指令注入 → 输入清洗 + 输出验证
- **数据泄露**：Agent 处理敏感数据时泄露风险 → 数据脱敏 + 审计日志
- **供应链攻击**：MCP 服务器/工具生态存在后门风险 → 签名验证 + 沙箱执行

### 7.3 组织与人力资源

- **岗位替代**：部分重复性知识工作面临自动化风险
- **技能鸿沟**：企业缺乏管理 Agent 的人才
- **信任问题**：人类不愿将关键决策交给 Agent
- **责任归属**：Agent 错误决策时的责任划分不明确

### 7.4 局限性

- **创意与战略**：Agent 在高度原创性、战略决策方面仍弱于人类专家
- **复杂物理世界**：纯数字 Agent 无法处理物理世界的不确定性
- **长尾异常**：罕见的边缘情况仍需人工处理
- **伦理决策**：涉及价值观判断的任务仍需人类最终决策
